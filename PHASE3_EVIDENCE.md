## Scope and approach

The shop, category, search and product routes are migrated onto the new system
through a **bridge layer**, `src/styles/catalog.css`, exactly as the shell was
in Phase 2. It targets the existing class names deliberately, so **not one line
of filtering, sorting, pricing, variant, eligibility or cart logic was touched**.
`ShopPage.jsx`, `Filters.jsx`, `VariantSelector.jsx`, `PurchaseActions.jsx` and
`SortSelect.jsx` are byte-for-byte unchanged.

What changed visually: category masthead, department and subcategory rails
(drawn underline from the leading edge, so it reads correctly in Arabic),
toolbar, filter groups, the product card (specimen on a plate — drawn frame, no
shadow, a measurement tick on the leading edge, quick-add rising from the base),
badges as drawn stamps, product-detail gallery and title, variant controls as
specification, and the search field.

## Performance

No dependency and no runtime code added to the catalog path. `catalog.css` is
part of the entry bundle with the rest of the design system. Card hover uses
`transform` only, so it stays off the main thread.

## Known limitations

- Levels A and B have **zero** products because no 3D model and no turntable
  sequence exists in the repository. The viewer supports both; the assets do not
  exist. Requirements are itemised per product in the matrix.
- The product-detail gallery remains the existing component (which is already
  Level C behaviour) with the tier disclosure added, rather than being replaced
  by `ProductViewer`. Replacing it would have meant re-implementing the lightbox
  and thumbnail behaviour for no user-visible gain; `ProductViewer` is the
  architecture that Levels A and B will use when assets land.
- Search remains the existing implementation, restyled. Its semantics and
  indexing behaviour are untouched, as required.

## External blockers

Product photography for 44 products, additional angles for 24 more, turntable
capture, and 3D models. All specified in `docs/PRODUCT_VIEWER_MATRIX.md`.

## Preserved — verified

Prices, SKUs, variants, sizes, colours, availability, eligibility, wholesale
minimums, the quote-only path, the coming-soon path, filtering, sorting, URL
query behaviour, cart operations and the Libya ready-to-ship rule are all
unchanged; the files that own them were not edited.
